## 摘要
车辆路径问题（VRP）是一类基础性的组合优化问题，在各种场景中有着广泛的应用。先进的优化求解器能够有效解决此类问题。然而，为求解器建模复杂的VRP变体通常需要大量领域专业知识，这限制了先进优化技术的可及性。在本文中，我们提出了强化学习增强的LLM智能体（RLEA），一种旨在自动化建模复杂VRP的多智能体框架。RLEA引入了一个使用Soft Q-learning训练的轻量级神经规划器，以高效编排基于LLM的智能体的动作。此外，我们为系统配备了进化记忆模块和检索增强生成技术，使智能体在生成和优化求解VRP的程序时，能够利用积累的经验和外部求解器知识。我们评估了跨多种求解器的48种不同VRP变体。实验结果表明，RLEA优于先前最先进的方法，成功率提高了16.67%，同时显著减少了运行时错误。这些结果验证了将强化学习与基于LLM的推理相结合对于自动化优化建模非常有效。附录可在以下网址获取：https://doi.org/10.5281/zenodo.19134435。

## Abstract
Vehicle Routing Problems (VRPs) are fundamental combinatorial optimization problems with widespread applications in various scenarios. The advanced optimization solvers can effectively solve such problems. However, modeling complex VRP variants for solvers often requires substantial domain expertise, which limits the accessibility of advanced optimization technologies. In this paper, we propose Reinforcement Learning Enhanced LLMAgents(RLEA), a multi-agent framework designed to automate the modeling of complex VRPs. RLEA introduces a lightweight neural Planner trained with Soft Q-learning to efficiently orchestrate the actions of LLM-based agents. In addition, we equip the system with an evolutionary memory module and retrieval-augmented generation, enabling the agent to leverage both accumulated experience and external solver knowledge during program generation and refinement for solving VRPs. We evaluated 48 distinct VRP variants across various solvers. The experimental results demonstrate that RLEA outperforms the previous state-of-the-ar method, achieving a 16.67% higher success rate while significantly reducing runtime errors. These results validate that integrating reinforcement learning with LLM-based reasoning is highly effective for automated optimization modeling. # 2. 方法论：核心思想、关键技术细节

## 2.1 总体架构
RLEA 是一个多智能体框架，包含三个核心组件：

- **Planner（规划器）**：轻量级神经网络，用 Soft Q-Learning 训练，负责根据当前建模状态选择执行动作。
- **Executor（执行器）**：由 LLM（DeepSeek-Reasoner）承担，根据 Planner 的动作生成或修正代码，并调用求解器。
- **Memory（记忆模块）**：包含 Collector（收集器）和 Memory Distiller（记忆蒸馏器）两个角色，将历史交互轨迹提炼为可复用的“成功经验”和“失败根因”经验。

## 2.2 动作空间设计
动作空间设为 `A = {Refine, RAG, MLEM}`：

- **Refine（ar）**：让 Executor 基于当前代码和错误反馈进行迭代调试与自修正，利用 LLM 的自校正能力；
- **RAG（ag）**：检索增强生成。先将问题分解为约束集合，再将每个约束作为查询，通过欧氏距离度量检索相关求解器文档，注入代码生成/修正过程中，弥补 LLM 参数中缺少的领域化知识；
- **MLEM（am）**：Meta-Learning with Evolved Memory（进化记忆元学习）。根据语义相似度从记忆池取出历史成功/失败样例作为 in-context demonstration，帮助智能体快速适应新约束组合。

## 2.3 Planner 训练：Soft Q-Learning
目标建模为带记忆增强的 MDP：`⟨S, A, P, R, γ, M⟩`。Planner 输出 Boltzmann 随机策略：

- `π(a | s) ∝ exp(Qθ(s,a)/α)`，通过温度参数 α 控制探索与利用的平衡。
- 训练采用 Soft Q-Learning，通过最小化 soft Bellman 残差更新 Q-network：
  - soft TD 目标为 `y_t = r_t + γ(1−d_t)·α log Σ exp(Qθ̄(s_{t+1},a')/α)`
  - 损失为 Q 预测与 soft 目标的均方误差。

**奖励设计**：设定相对最优间隙，`δ_t = (y_t − y*) / y*`，其中 y* 为专家标定最优目标值。奖励为：
- 若得到可行解：`r_t = 1 / (1 + δ_t)`，奖励随解质量逼近最优趋近于 1；
- 否则：`r_t = 0`。

## 2.4 记忆演化与推理
- **记忆演化**：Collector 记录每次执行的成功总结/失败原因；Memory Distiller 在需要时按语义相似度检索 Top-K 历史经验，作为 MLEM 动作的上下文。
- **训练过程**：Planner 与环境交互产生轨迹，存入 replay buffer 用于深度学习更新；记忆池独立维护，供 MLEM 使用。
- **推理过程**：冻结 Planner 参数。先用 Executor 直接从描述生成代码，若不成功，则由 Planner 在后续步骤中低成本地选择动作，指导 Executor 迭代生成/修正代码；当获得可行解且最优间隙低于 5% 时提前停止。

# 8. 缺点与局限

- **成功率仍有较大提升空间**：即便在最好的配置下（OR-Tools 上 62.50%），仍有近四成的 VRP 变体无法自动建模成功；Gurobi 上成功率更是不足一半，距“可靠自动化”的实用目标尚有明显距离。
- **依赖多个外部大模型，成本与稳定性存疑**：系统需要 DeepSeek-Reasoner（执行）、GPT-4o（记忆蒸馏）等多个商用/大模型协同，实验未报告完整的 API 调用成本与 token 消耗；一旦任一大模型接口升级或行为漂移，整体性能可能受到影响。
- **Planner 泛化性未充分验证**：Planner 是在固定的 48 种约束组合（且基本 VRP 结构固定）上训练与测试的，未验证其能否泛化到训练分布之外的、全新的约束类型或非 VRP 类优化问题；对于需要额外软约束或复杂目标函数的问题，动作空间是否足够也未讨论。
- **奖励设定依赖“专家最优值 y\*”**：每个 VRP 变体都需要专家预先标定最优解才能在训练时提供稠密奖励，这一人工成本在扩展至新问题域时不可忽视；若 y\* 本身不准确，奖励信号会被污染。
- **离线 vs 在线记忆的性能悖论缺乏深入解释**：按常理在线记忆应随交互积累而持续改进，但实验显示在线版本成功率反而低于离线版本；作者仅笼统归因于“在线收集的经验噪声较大”，未能给出严谨的分析（如记忆污染机制、检索噪声影响等）。
- **统计严谨性不足**：只报告了 3 次运行的平均结果，未给出方差、置信区间或显著性检验；鉴于 LLM 输出本身具有随机性，结论的稳健性难以完全确认。
- **缺少真实场景验证**：所有测试均为合成约束组合（基准 VRP 上叠加已知约束），未在真实物流/供应链场景的异构、非结构化数据上验证方法的实用价值。

# 9. 启示与潜在改进方向

- **更丰富的动作空间设计**：当前仅三个粗粒度动作（Refine/RAG/MLEM），未来可细化为“替换求解器”“拆分约束”“重写目标函数”“切换建模范式（如 CP-SAT vs MIP）”等更精细的原子动作，让 Planner 具备更强的调度能力。

- **解质量导向的评估与奖励**：将评估从“能否运行成功”推进到“求解质量对比专家解的下界差距”，并在奖励中引入代码执行时间、求解器超时率等效率指标，避免只追求可行而忽视效率。
- **更强的记忆管理**：可引入记忆冲突检测与去重机制，为每条经验附带上下文指纹（如约束签名向量），避免检索到“貌似相似但实际不兼容”的误导性样例。
- **自适应在线学习**：设计置信度阈值或经验成熟度指标，仅将“被后续验证过”的高置信度经验写入记忆池，从而规避在线记忆中噪声积累导致性能下降的问题。
- **扩展至更广的优化问题族**：方法本身并不绑定 VRP，将其迁移到排产调度、网络设计、资源配置等其他 NP-hard 问题上，是检验框架通用性的关键一步。
- **工程化落地的方向**：可训练一个统一的“问题分类器”来替代人工判断问题类型，并集成到开源求解器平台中，让用户仅用自然语言即可完成“描述→运行→看结果”的完整闭环。

# 10. 总结性评价

RLEA 是一篇**将强化学习嵌入 LLM 智能体编排层的代表性工作**，其核心贡献不在于某一个 NLP 技巧或提示策略的改进，而在于提出了一种**“轻量策略网络调度重型 LLM 工具链”**的系统性框架。它精准地抓住了现有 LLM 自动建模方法的两个痛点——**决策成本高**（每步都调用 LLM）和**知识利用浅**（只依赖外部检索，缺乏历史经验沉淀），并以 Soft Q-Learning + 记忆演化给出了一个工程上可行、实验上有效的答案。

论文的实验设计覆盖面广、对比公平、消融完整，尤其在 OR-Tools 平台上 62.50% 的成功率相对此前 SOTA 方法 DRoC 的 45.83% 有了实质性提升，证明“强化学习引导的智能体协作”这一思路具有真实潜力。然而，其局限也同样明显：成功率尚不足以支撑工业级全自动建模、奖励依赖专家标定、统计报告不完整、在线学习机制不够健壮等，都意味着该方法距离“成熟产品”仍有距离。

总体来看，这是一篇**问题选得好、方法组合巧、实验做得扎实**的高质量工作。它为“LLM 用于组合优化建模”这一细分方向指明了一条可复现、可扩展的前进道路——**不是让 LLM 直接替代求解器或建模专家，而是让 LLM 在强化学习策略的调度下，成为专家求解器与普通用户之间的桥梁**。其“RL 作为大脑、LLM 作为手脚、记忆作为知识库”的架构理念，对未来通用优化自动化助手的设计具有持续的借鉴价值。
